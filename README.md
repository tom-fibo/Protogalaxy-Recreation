This is a Godot game about creating a custom spaceship to fight a random AI-controled enemy, where individual ship components can be damaged and fail to function. It is a recreation (with permission) from the [original scratch game](https://scratch.mit.edu/projects/1045044288/) to both learn Godot, and use the features of a full game engine to add more realistic physics and support more complex components & ships. AI was not used.
